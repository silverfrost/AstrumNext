Astrum Next Releases

This contains releases for Astrum Next as documented on [http://astrum.runasp.net](http://astrum.runasp.net). 
Once downloaded and running on your Spectrum Next you should be able to use the update code in AstrumUpdater.bas

Place in a folder called Astrum and run Astrum.bas

There is a simpler, and more importantly, 'Spectrum Next' way to get Astrum Next for those who have a Wi-Fi enabled Next:

* Create a directory called Astrum using the standard Next file browser
* Go in to the Astrum directory and go to command line and type:
.http get -h astrum.runasp.net -u /a/a.bas -f a.bas
* You should now have a file called a.bas which you can load and run - it should download the rest of Astrum Next. a.bas is just a copy of AstrumUpdater.bas renamed and put in a place that is easy to type.
